# 이미지 생성 프롬프트 가이드

이미지 생성 프롬프트를 작성할 때 다음 6가지 기준을 체계적으로 구성한다.

## 6가지 프롬프트 축

| 축 | 질문 | 설명 |
|---|---|---|
| **피사체 (Subject)** | 누가 있는가? | 인물, 동물, 사물 등 주요 대상 |
| **동작 (Action)** | 무엇을 하는가? | 피사체의 행동, 포즈, 상호작용 |
| **카메라 (Camera)** | 어디서 보는가? | 앵글, 구도, shot type (close-up, wide, etc.) |
| **조명 (Lighting)** | 빛이 어디서 오는가? | 광원의 방향, 종류, 분위기 |
| **환경 (Environment)** | 어디이고 언제인가? | 배경, 장소, 시간대, 계절 |
| **스타일 (Style)** | 어떤 느낌인가? | 아트 스타일, 장르, 무드, 레퍼런스 |

## 사용 예시

프롬프트 작성 시 위 6가지 축을 순서대로 질문하며 빠짐없이 구성하도록 돕는다.
